                          ARCHITECTURE
================================================================================

COMPONENT HIERARCHY:
  Timeline
  ├── Controls Bar
  │   ├── SnapToggle (S key toggle)
  │   └── ZoomControls (buttons + dropdown)
  ├── TimelineRuler (click-to-seek)
  ├── Tracks Area
  │   ├── SnapIndicators (overlay, z-40)
  │   ├── Playhead (overlay, z-50)
  │   └── Tracks (from previous task)
  └── Keyboard Shortcuts Help Bar

STORE INTEGRATION:
  useTimelineStore:
    - zoom: number (0.25-8)
    - snapEnabled: boolean
    - scrollPosition: number
    - tracks: Track[]
    
  usePlaybackStore:
    - currentTime: number
    - duration: number
    - playing: boolean
    - seek(time), play(), pause()

PERFORMANCE OPTIMIZATIONS:
  • requestAnimationFrame for smooth 60fps updates
  • useMemo for tick calculation (prevents re-renders)
  • Viewport culling (only render visible elements)
  • Debouncing (50ms for wheel zoom)
  • Early exit in snap detection
  • Spatial indexing for snap points
