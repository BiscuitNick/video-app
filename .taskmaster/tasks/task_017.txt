# Status: pending
# Dependencies: 14, 15, 16
# Priority: high
# Description: Create FastAPI routes for project CRUD operations, autosave, duplication, and versioning per API specification
# Details:
Create ffmpeg-backend/src/app/api/v1/projects.py with FastAPI router. Implement POST /projects endpoint: create project with name/aspect_ratio/timebase_fps, automatically create linked Composition with matching settings in same transaction, return full Project with nested composition. Implement GET /projects endpoint: list projects with pagination (page, per_page), search by name query parameter, sort by last_modified_at or created_at, return lightweight project list without full composition data for performance. Implement GET /projects/{id} endpoint: get single project with full composition including tracks/clips/transitions JSONB data, return complete project structure. Implement PUT /projects/{id} endpoint (autosave): accept project name, thumbnail_url, and full composition object with tracks/clips/transitions, update last_modified_at timestamp, implement optimistic locking using updated_at comparison to prevent concurrent edit conflicts, return updated project. Implement POST /projects/{id}/duplicate endpoint: deep copy project and composition, append 'Copy' to project name, generate new UUIDs, return duplicated project. Implement GET /projects/{id}/versions endpoint: return version history if versioning implemented (future feature). Implement POST /projects/{id}/versions/{v}/restore endpoint: restore project to previous version (future feature). Use AsyncSession for all operations, proper error handling, integrate with existing Composition model, handle project-composition one-to-one relationship carefully in transactions.
